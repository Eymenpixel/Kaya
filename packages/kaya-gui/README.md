# Kaya-GUI

Kaya-GUI is a graphical companion to the Kaya command-line package manager. This first starter lists installed packages, installs a local `.kay` file, and removes a selected package by calling Kaya's CLI. Repository browsing and updates will be added when Kaya's repository API is ready.

Launch with `kaya-gui`. The Kaya executable must be available on Nexora's `PATH`.
